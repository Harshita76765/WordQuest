# WordQuest 
A simple word-guessing game developed independently using Python.

## About the Project
WordQuest is a command-line game where players try to guess a randomly selected secret word, one letter at a time.

## Features
- Random word selection
- Letter-by-letter guessing
- Five lives for each game
- Hint system
- Repeated guess detection
- Player leaderboard to track wins and losses
- CSV file handling to save player records

## Technologies Used
- Python
- Random module
- CSV module

## How to Run
1. Install Python.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:
python wordquest.py
